How to run STIG Checker — no technical skill needed

1. Unzip this folder. Keep these files together; do not move one file to the Desktop.

2. Windows: double-click "STIG Checker.bat"
   Mac: right-click "STIG Checker.command" → Open → Open

3. Windows may say "Windows protected your PC".
   Click More info, then Run anyway. Once.

4. If a box asks to download Python, click Yes.
   That is a private copy from python.org. It is not a system install
   and does not need an administrator password.

5. A page opens in your browser. If you downloaded this from the website,
   your selected rules are already loaded — read and approve them, then scan.
   Otherwise pick MacBook or Windows PC and follow the page.

You do not need the command line.
Approve checks under your own name. Nothing runs until you do.
A PDF report is saved with the other reports (Show files).
