Optional public note

Used this?

Himanshu Saxena · stig.hsaxena.com/used.html

If you tried the site or the local scanner and you are willing to say so on the public record, you can leave a short note. That is optional. Silence is the default. For a named review that is approved by hand before it appears, use Reviews instead.

No invented quotes. This page is an invitation, not a wall of praise. There are no sample testimonials here. If none have been posted, that is the true state.

What to send (and what to leave out)

  • Organisation type is optional (school, clinic, small office, home lab, or “prefer not to say”). A name is not required.
  • Say what you used: this website, the downloaded scanner, or the command line.
  • A sentence or two you are willing to keep public is enough.
  • Do not include names of people, patient or student data, hostnames, IP addresses, screenshots of real machines, or other personal information.

Two ways to send it

Open a GitHub issue Email 1992.hsaxena@gmail.com

The issue form is public and stays on the repository. That is the preferred path for a note you want others to be able to see. Email is private unless you say it may be quoted.

GitHub Discussions are not required. If the repository enables Discussions later, the same optional note can go there instead of an issue. Until then, use the issue template.

A note here is not an endorsement by the Department of Defense or DISA, and it is not a usage metric. See what we do not claim.
